    计算说明

    • MA5 / MA10 / MA20：分别为最近 5 / 10 / 20 根K线收盘价的简单移动平均线（MA = Moving Average），日K下即 5 / 10 / 20 日均线，颜色依次为橙 / 紫 / 蓝；不足对应根数时不绘制，用于观察短、中、长期均线趋势与金叉死叉。
    • 均线一阶导数 dMA/dt：先计算 MA5 / MA10 / MA20，再对均线序列求一阶导数；内部点使用非均匀时间步长的三点中心差分，首尾点使用四点前向 / 后向差分。均线不足窗口时不绘制对应导数。
    • 均线二阶导数 d²MA/dt²：在均线序列上使用非均匀时间步长的二阶差分公式，刻画趋势的加速度；首尾点同样采用四点公式。
    • 零线：白色虚线标记 0 值；纵轴按导数值自动缩放，仅在 0 落入数据范围时显示，避免压缩数据曲线。
    • 时间变量：“真实时间间隔”以自然时间计算，休市、午休与节假日间隔计入其中；“交易时间”剔除休市，按交易分钟 / 交易日 / 周 / 月等间距计算；“K线序号”则每根K线为 1 个单位。
    • 时间对齐：日 / 周 / 月K的历史时间戳对齐到收盘时刻；交易时段内的最后一根K线使用最新报价时间，避免用午夜时间低估实时变化率。
    • 平滑窗口：默认 1 不额外平滑；大于 1 时先对 MA 均线再做简单移动平均，再计算导数，可进一步降低噪声，但会引入滞后。
    • 数据清洗：剔除价格非正、最高价 / 最低价与开收盘不一致的异常K线，按时间排序并对重复时间戳保留最新一条，再截取所需数量。
    • 复权：A股日 / 周 / 月K支持前复权与后复权；分钟K线以及港股、美股仅提供不复权数据，状态栏会提示实际复权方式。
    • 数据源：可选富途牛牛、腾讯行情、东方财富备用通道；自动模式在配置富途 Token 后优先使用富途，失败时依次回退腾讯与东方财富。
    • 每日龙头股：取东方财富涨停板池，按连板数从高到低排序并分页展示；"行业统计"按行业聚合涨停数、占比、连板、封单与成交额，点击行业可筛选个股，点击个股可加载K线。数据仅供学习研究，不构成投资建议。
    • 富途牛牛：需设置环境变量 FUTU_ACCESS_TOKEN（或 FUTU_TOKEN）为 OAuth access_token，具备 quote:read 权限；未配置时选择“富途牛牛”会返回错误。仅用于学习研究，不构成任何投资建议。
